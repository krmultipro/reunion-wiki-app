# Guide de publication de contenu SEO – Réunion Wiki

## Objectif

Ce guide explique comment créer et publier du contenu SEO de qualité sur Réunion Wiki via l'interface d'administration.

L'objectif est de publier des pages utiles aux habitants et visiteurs de La Réunion tout en améliorant le référencement naturel du site.

---

## Sélections sociales dynamiques

Les pages suivantes sont créées automatiquement par la migration :

- Youtubeurs réunionnais
- Créateurs Instagram réunionnais
- TikTokeurs réunionnais
- Créateurs réunionnais sur Facebook

Il ne faut pas les recréer manuellement. Elles restent modifiables dans
`Admin → Contenu SEO` pour personnaliser le titre, le résumé, le contenu et les
métadonnées. Leur slug est volontairement verrouillé afin de préserver l'URL.

Les fiches affichées sont alimentées automatiquement : un talent publié apparaît
dans chaque sélection correspondant aux URLs sociales renseignées dans sa fiche.

---

# 1. Créer un nouveau contenu

Depuis l'administration :

```text
Admin
→ Contenu SEO
→ Nouveau contenu
```

Remplir les champs suivants :

### Titre

Titre principal de la page.

Exemple :

```text
Youtubeurs réunionnais
```

---

### Slug

Le slug correspond à l'URL.

Exemple :

```text
youtubeurs-reunionnais
```

L'URL générée sera :

```text
https://reunion-wiki.re/youtubeurs-reunionnais
```

---

### Résumé

Courte description du contenu.

Exemple :

```text
Découvrez les principaux youtubeurs et créateurs de contenu de La Réunion.
```

---

### Contenu

Corps principal de la page.

Utiliser :

- des titres
- des paragraphes courts
- des listes lorsque c'est pertinent

---

### Image mise en avant

Image principale associée au contenu.

Elle peut être utilisée :

- dans les aperçus
- dans les partages sociaux
- dans les futures évolutions SEO

---

# 2. Les statuts

## Brouillon

Le contenu est enregistré mais non visible publiquement.

Utiliser ce statut lorsque :

- le contenu n'est pas terminé
- la relecture n'est pas faite
- les informations sont incomplètes

---

## Publié

Le contenu devient visible publiquement.

Il apparaît :

- sur son URL
- dans le sitemap

---

## Archivé

Le contenu n'est plus visible publiquement.

Utiliser ce statut pour :

- les contenus obsolètes
- les pages à retirer temporairement

---

# 3. Les champs SEO

## Meta Title

Titre affiché dans les résultats Google.

Exemple :

```text
Youtubeurs Réunionnais : Les créateurs de contenu de La Réunion
```

Recommandation :

```text
50 à 60 caractères
```

---

## Meta Description

Texte affiché sous le résultat Google.

Exemple :

```text
Découvrez des youtubeurs et créateurs de contenu réunionnais qui contribuent à la vie culturelle et numérique de La Réunion.
```

Recommandation :

```text
140 à 160 caractères
```

---

# 4. Convention de nommage des slugs

## Bonnes pratiques

Utiliser :

- minuscules
- mots séparés par des tirets
- pas d'accents
- pas de caractères spéciaux

Exemples :

```text
youtubeurs-reunionnais
photographes-reunion
humoristes-reunionnais
restaurants-saint-pierre
que-faire-a-saint-denis
```

---

## À éviter

```text
Test123
NouvellePage
Ma-Page-Version-2
page_test
```

---

# 5. Conseils de rédaction SEO

## Écrire pour les humains

Toujours privilégier :

- la clarté
- l'utilité
- la lisibilité

---

## Utiliser des titres

Exemple :

```text
H1 : Youtubeurs réunionnais

H2 : Créateurs à découvrir

H2 : Créateurs spécialisés voyage

H2 : Créateurs spécialisés humour
```

---

## Éviter le bourrage de mots-clés

Mauvais exemple :

```text
Les youtubeurs réunionnais sont des youtubeurs réunionnais qui font des vidéos de youtubeurs réunionnais.
```

---

## Privilégier les informations utiles

Répondre à de vraies questions :

- Qui sont-ils ?
- Que proposent-ils ?
- Où les suivre ?
- Quel type de contenu proposent-ils ?

---

## Vérifier les informations

Toujours privilégier :

- les sources officielles
- les informations publiques
- les données vérifiables

---

# 6. Recommandations pour les images

## Nom de fichier

Préférer :

```text
youtubeurs-reunionnais.jpg
photographes-reunion.jpg
personnalites-reunionnaises.jpg
```

Éviter :

```text
IMG_1234.jpg
photo-finale-v3.jpg
```

---

## Taille recommandée

Largeur :

```text
1200 px
```

Format :

```text
JPG
PNG
WEBP
```

---

## Poids recommandé

Objectif :

```text
moins de 300 Ko
```

- [ ] Liens vérifiés
