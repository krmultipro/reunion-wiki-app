# Décisions et ADR

Ce dossier conserve les décisions structurantes du projet.

## Convention

- `ADR-XXX-sujet.md` pour une décision d'architecture ou d'organisation
  durable ;
- un identifiant n'est jamais réutilisé ;
- les statuts possibles sont `Proposé`, `Accepté`, `Refusé` et `Remplacé` ;
- un ADR accepté n'est pas réécrit pour changer son sens ;
- une nouvelle décision crée un nouvel ADR qui indique l'ADR remplacé ;
- les corrections orthographiques qui ne changent pas le sens restent
  autorisées.
