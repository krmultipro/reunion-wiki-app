# Architecture

Ce dossier regroupe les diagrammes techniques du projet Réunion Wiki.

Organisation :

- `diagrams/`
  - fichiers sources `.drawio`, `.puml`, etc.

- `images/`
  - exports PNG, SVG ou PDF

Les diagrammes décrivent :

- l'architecture générale ;
- la base de données ;
- les diagrammes UML ;
- les diagrammes de séquence ;
- les flux applicatifs.
